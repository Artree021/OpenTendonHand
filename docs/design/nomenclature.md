## Joint names

Pattern: `<finger>_<joint>`.

| Finger prefix | Joints |
| --- | --- |
| `thumb` | `cmc`, `mcp`, `ip` |
| `index` | `mcp`, `pip`, `dip` |
| `middle` | `mcp`, `pip`, `dip` |
| `ring` | `mcp`, `pip`, `dip` |
| `little` | `mcp`, `pip`, `dip` |

Example: `index_pip` is the proximal interphalangeal joint of the index finger.

## Abduction and flexion

| Suffix | Meaning |
| --- | --- |
| `_flex` | Flexion/extension axis |
| `_abd` | Abduction/adduction axis |
