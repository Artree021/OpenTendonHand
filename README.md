# OpenTendonHand

**开源高自由度线驱灵巧手**
An open-source high-DOF tendon-driven dexterous hand.

本仓库公开这款灵巧手的机械模型、电路板与设计文档，供学习、复现与二次开发使用。

## 目录

| 目录 | 内容 |
| --- | --- |
| `solidworks/` | SolidWorks 2025 源模型（.SLDPRT / .SLDASM），保留完整特征 |
| `step/` | STEP 中性格式模型，任意 CAD 软件均可打开 |
| `pcb/` | 电路板文件 |
| `docs/` | 设计文档（Word） |

## 使用说明

- 单位：毫米（mm）。
- 只想看结构或换软件打开：用 `step/`。
- 要改设计：用 `solidworks/`，特征完整可编辑。
- 本仓库为设计归档，以发布文件为主，不承诺持续更新。
